# Spectral Shadows

Немкова Анастасия Романовна

3D-головоломка от первого лица, где тени от объектов приобретают разные физические свойства в зависимости от цвета света, позволяя игроку переходить пропасти, направляя свет фонаря.

## Суть игры

Игрок исследует таинственные острова, разделённые пропастями. С помощью специального фонаря, меняющего цвета (RGB), можно проецировать тени от объектов на землю. Каждая тень обретает уникальные физические свойства:

- 🔴 **Красный свет** → Высокое трение (медленное, контролируемое движение)
- 🟢 **Зелёный свет** → Упругость (высокие прыжки, отскоки)
- 🔵 **Синий свет** → Скольжение (быстрое перемещение)
- ⚪ **Белый свет** → Обычная физика

**Цель:** Собрать все кристаллы, используя тени как мосты и платформы.

## Две сложные реализованные механики

1. Система автоматически адаптирует форму и поведение тени под геометрию объекта и окружение. Реализована через два взаимодополняющих модуля:

- Наземные тени: 
  - Raycast-поиск поверхности земли с буфером высоты.
  - Генерация плоского дискового меша на основе габаритов объекта.
  - Плавное появление/исчезновение и таймеры.
  - Автоматическое масштабирование в реальном времени при движении игрока или изменении угла света.

- Направленные тени-мосты:
  - Проецирование вытянутой платформы вдоль вектора.
  - Фиксация направления в момент активации для стабильности физики.
  - Таймер сохранения тени после выключения света, позволяющий игроку завершить переход.
  - Динамическое масштабирование длины в зависимости от дистанции до источника света.


2. Фонарь с гироскопической стабилизацией и сохранением углового момента
Стандартное управление камерой заменено на физически обоснованную модель вращения с инерцией:

- Накопление угловой скорости при движении мыши.
- Экспоненциальное демпфирование для плавного затухания вращения.
- Гироскопическая стабилизация: автоматический возврат к нейтральному углу при отсутствии ввода.


### Основные скрипты

 Файл | Описание |
|------|----------|
| **PlayerController.cs** | Управление игроком: WASD-движение, камера (мышь), прыжки, определение поверхности под ногами для применения физики, сбор кристаллов|
| **FlashlightController.cs** | Управление фонарём: гироскопическая стабилизация, инерция вращения, переключение цветов (1/2/3/0), включение/выключение (F) фонарика, управление компонентом `Light` |
| **GroundShadowProjector.cs** | Система наземных теней: Raycast-проецирование на землю, генерация дискового меша, плавное масштабирование/фейд, таймеры жизни, смена физики по цвету |
| **ShadowProjector.cs** | Система направленных теней-мостов: проекция вдоль луча, фиксация направления, таймер сохранения после выключения света, динамическое масштабирование |
| **PlayerAudioManager.cs** | Аудиосистема: шаги, прыжок, сбор кристалла, победа, падение|
| **VictoryManager.cs** | Экран победы, кнопка "Играть снова", управление курсором |
| **AbyssTrigger.cs** | Детектор падения в пропасть |
| **CrystalUI.cs** | Интерфейс кристаллов: отображение количества собранных кристаллов, анимация сбора|
| **DeathMessageUI.cs** | Система сообщений о падении |

### Материалы

| Тип | Название | Описание |
|-----|----------|----------|
| **Material** | `Mat_Shadow` | Полупрозрачный URP материал для визуализации теней (Unlit + Transparent) |
| **Material** | `Mat_GroundShadow` | Базовый материал для наземных теней |
| **PhysicMaterial** | `PhysMat_Bouncy` | Упругость |
| **PhysicMaterial** | `PhysMat_Grippy` | Трение|
| **PhysicMaterial** | `PhysMat_Slippery` | Скольжение|
| **PhysicMaterial** | `PhysMat_Normal` | Стандартная физика |


## Управление

1. **WASD** — Перемещение
2. **Мышь** — Поворот камеры и фонаря
3. **Пробел** — Прыжок
4. **F** — Включить/выключить фонарь
5. **1/2/3/0** — Сменить цвет фонаря (Красный/Зелёный/Синий/Белый)
